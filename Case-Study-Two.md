## Case Study 02: Slow Computer

### Problem Statement

An employee reports that their  laptop runs very slowly on Windows. Applications take a long time to open, the system often freezes, and multitasking is difficult. The employee needs the laptop to work efficiently to complete an important work assignment.


### Initial Questions

1. When did the computer start running slowly? Did the issue begin after installing software, updating Windows, or making system changes?

2. Does the computer run slowly all the time, or only when using specific applications?

3. How much free storage space is available on the laptop?

4. Are multiple applications running in the background, or does the laptop become slow even when only one application is open?

### 3. Possible Causes

- Too many applications or background processes running simultaneously.

- Insufficient RAM or high memory usage.

- Low disk space or a slow storage drive.

- Outdated drivers, pending Windows updates, or software conflicts.

- Malware or unwanted programs consuming system resources.

### 4. Troubleshooting Process

1. **Check running applications.** Open Task Manager by pressing `Ctrl + Shift + Esc`. Review the running applications and close unnecessary programs that are consuming excessive CPU, memory, or disk resources.

2. **Inspect system performance.** In Task Manager, check the CPU, Memory, and Disk usage percentages. Identify whether any process is consistently using excessive resources.

3. **Check available storage space.** Open File Explorer, select **This PC**, and review the available space on the system drive. If the drive is nearly full, remove unnecessary temporary files using Windows Storage settings or Disk Cleanup.

4. **Review startup applications.** Open Task Manager and select **Startup apps**. Disable unnecessary applications from launching automatically when Windows starts. Avoid disabling important security software or company-managed applications.

5. **Scan for malware.** Use Windows security to run a scan. Remove any threats identified by either removing them or placing them into quarantine as per company policy.

6. **Check for system and driver updates.** Use Windows update to ensure any approved updates are installed. Make sure that device drivers are up-to-date and are compatible with the laptop. If necessary restart the device.



7. **Analyze the results.** Observe whether performance improves after each troubleshooting step. If the CPU or memory is still being used at an unusual rate then look into which process is causing it. If there are still intermittent freezes and a high disk usage then, check system files, hardware or memory.


### Resolution

For this example, suppose the investigation identifies multiple unnecessary startup applications and background processes as the main cause of the slow performance.

After it is determined that the applications are not needed for business operations, unnecessary startup applications are disabled and unneeded programs are closed. The laptop is then restarted, and Task Manager is checked to verify that resource usage has lessen. 

Several applications are tested, it is confirmed that they open quicker, and it is verified that the system responds normally when switching between tasks. The employee confirms that the laptop is performing better and can now complete the task efficiently.


## 6. Preventive Measures

- Close applications that are not currently needed to reduce unnecessary resource usage.

- Regularly review startup applications and disable unnecessary entries.

- Maintain sufficient free storage space by removing unnecessary files and applications.

- Keep Windows, device drivers, and security software updated according to company policy.

- Run regular malware scans using approved security tools.

- Report recurring performance problems to the IT support team, especially when they may indicate hardware failure or insufficient system resources.

### Conclusion

The case demonstrates a systematic approach to troubleshooting a slow computer. By reviewing running processes, checking CPU and memory usage, inspecting storage space, managing startup applications, and scanning for malware, a technician can identify potential performance bottlenecks and apply appropriate solutions. Regular maintenance and monitoring help maintain system performance and improve employee productivity.
